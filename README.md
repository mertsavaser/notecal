# 🍎 NoteCal – Calorie Tracking App (Live Product)

A production-ready calorie tracking mobile application focused on simplicity, speed, and real user experience.

🚀 **Available on App Store**
(https://apps.apple.com/tr/app/notecal-tracker/id6757075482?l=tr)

---

## 📱 Overview

NoteCal is a minimal and user-friendly calorie tracking application designed to make daily logging fast and frictionless.

The goal was not to build a complex fitness app, but a **clean, usable product that people actually use consistently**.

---

## 🛠️ Tech Stack

* **Frontend:** Flutter
* **Backend:** Firebase
* **Auth:** Google & Apple Sign-In
* **Storage:** Firebase Storage
* **Architecture:** Scalable mobile + cloud integration

---

## ⚙️ Key Features

* Daily calorie & macro tracking
* Custom food creation
* Weekly progress tracking
* Clean and minimal UI/UX
* Real-time data sync
* Secure authentication

---

## 🧠 Technical Highlights

* Designed a **scalable data structure** for food and user tracking
* Implemented **real-time updates** with Firebase
* Built a **clean UX flow** optimized for speed and usability
* Managed full lifecycle: design → development → deployment
